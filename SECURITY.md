# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.4.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within **NEXUS OS**, please do not open a public issue.

Instead, please send an advisory report to **[Shubh Thakur](https://github.com/shubhthakur363-oss)** via private communication or GitHub Security Advisories.

Please include:
- Description of the vulnerability and potential attack vectors.
- Steps to reproduce or proof-of-concept payload.
- Suggested mitigations if known.

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to patch and disclose responsibly.
