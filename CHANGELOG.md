# Changelog

All notable changes to **NEXUS OS** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.4.0] - 2026-08-25

### Added
- **Obsidian Glassmorphism & Cyber Aurora Design System**: Complete visual rebrand with deep void aesthetics (`#07080D`), ambient blur orbs, and glassmorphic card overlays.
- **Dynamic Executive Telemetry**: Real-time time-of-day greeting engine ("Good Morning/Evening, Shubh") and live system status chips.
- **Initials Avatar Engine**: Dynamic gradient initial avatar chips for all sales audit table leads.
- **OpenGraph & Schema.org Metadata**: Structured JSON-LD payload and canonical URL linking to production edge endpoint (`https://terra-dashboard-seven.vercel.app/`).
- **Production CI Pipeline**: GitHub Actions CI workflow for verifying asset integrity and JavaScript syntax.

### Changed
- Replaced legacy color palettes with high-contrast Cyber Aurora tokens (`#00F2FE` cyan, `#7928CA` neon violet, `#10B981` emerald).
- Upgraded SVG sparkline spline curves with multi-stop gradient glow fills and drop-shadow anchors.
- Refactored `localStorage` key names to avoid cross-tenant configuration collisions.

## [1.0.0] - 2026-05-20

### Added
- Initial release with Supabase RPC endpoints (`get_sales_dashboard`, `get_destination_sales`, `get_product_sales`).
- High-fidelity interactive local demo fallback engine.
- Vector world map with hotspot beacons.
- Multi-column sortable audit leaderboard with RFC 4180 CSV export.
